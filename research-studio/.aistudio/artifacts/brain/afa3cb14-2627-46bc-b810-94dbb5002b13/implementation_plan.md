# 科研工作台全功能设置中心重构与全站配置收敛方案

完善并重构科研工作台偏好设置系统，**将所有涉及到需要设置的功能、需要配置的服务全部集中在“偏好设置”（SettingsModal）中统一修改**；同时**彻底清理其余业务页面中分散、重复的内联配置面板**（如 RAG Studio 页面内的分块与向量下拉设置、文献导入弹窗内的解析参数等），其余页面一律直接消费全局统一设置，并提供单键跳转至设置中心的通道。

遵循用户要求：**编写页面时保持简洁、高密度紧凑排布、去除一切冗余说明与装饰文字、即改即生效**。

---

## User Review & Critical Decisions

> [!IMPORTANT]
> 核心原则确立（根据用户最新审查意见）：
> - **全局唯一配置真理源（Single Source of Truth）**：所有服务、模型、算法、沙箱与环境参数**必须且仅能在“设置”中修改**。
> - **其余页面消除冗余设置**：
>   - **RAG Studio 页面**：移除原页面顶部的“参数”折叠面板及其内部重复的 Chunk Size、Embedding 模型、度量方式选择控件；分块与检索逻辑直接读取全局统一设置，保留只读状态指示并提供 `[偏好设置 ⌘,]` 快捷跳转。
>   - **文献中心与导入页面**：移除文献导入弹窗中重复的 MinerU 流水线模式、公式/表格抽取重复开关；直接根据全局设置中的 `mineruConfig` 与 `academicConfig` 自动化执行。
>   - **Agent 对话页面**：顶部模型指示与全局设置深度同步，点击可直接呼出设置面板的“模型与服务”标签。
> - **界面极简约束**：去除所有“新手引导式”长段落与说明文字，使用高密度紧凑表单（标签 + 控件 + 微型状态灯），实现“即改即存即生效”。

- **确认决定 1（类型体系收敛）**：在 `src/types/research.ts` 中将 `ModelSettings` 扩展为包含学术源、沙箱执行、检索超参、Agent 护栏的完整 `AppSettings` 集合，并在全局 `App.tsx` 中作为主状态分发给所有视图。
- **确认决定 2（其余页面改造）**：审查 `RagStudioView`、`LiteratureHubView`、`LatexEditorView`、`AgentChat`，将其中的本地 state 配置项切换为使用全局 settings，去除重复 UI。
- **确认决定 3（统一设置中心分类）**：设置中心划分为 6 大分类：`模型与服务`、`向量与 RAG`、`文献与解析`、`编译与沙箱`、`智能体安全`、`偏好与备份`。

## 1. Overview & Core Concept

- **What It Does**:
  - 构建全站统一的基础设施控制塔。任何涉及到模型供应商、API 密钥、向量检索算法、学术检索源、编译执行沙箱、Agent 运行拦截与界面偏好的配置项，均在此集中管理。
  - 其余科研子工作台专注于科研内容创作与检索检视，不再承载任何底层的参数修改表单，界面大幅净化。
- **Target Audience / Persona**:
  专业科研学者与算法研究员，习惯于类似 VS Code / JetBrains / Obsidian 的全局 Settings 偏好设置模式，追求界面清爽与集中化控制。
- **Key Value**:
  消灭“同一参数在多处可调且状态不一致”的混乱，确立清晰唯一的全局配置规范。

### Settings Tab Detailed Controls (Strictly No Fluff)

1. **[1] 模型与服务 (Models & Providers)**:
   - 供应商切换（Gemini / DeepSeek / Claude / OpenAI / 本地 Ollama / 自定义）。
   - 模型名称（Model ID）、API Key、Base URL。
   - 采样温度（Temperature 滑块 0.0–1.0）、最大输出 Token、流式传输开关、深度思考（Thinking）开关。
   - 自定义供应商表格：名称、URL、模型列表、启用状态、删除、测试连通（测延迟）。

2. **[2] 向量与 RAG (Vector & Retrieval)**:
   - 向量嵌入模型（text-embedding-004 / BGE-M3 / text-embedding-3-small / 自定义 Provider）。
   - 分块策略：子块大小（Chunk Tokens 128/256/512/1024）、重叠大小（Overlap Tokens）。
   - 混合检索权重分配：RRF 平滑常数 $k$、Dense 向量权重、Sparse 关键词权重、论文级权重。
   - 重排序（Reranker）：开启开关、重排序模型名、相似度截断阈值（0.0–1.0 滑块）、父块扩展开关。

3. **[3] 文献与解析 (Literature & MinerU)**:
   - **MinerU 解析引擎**：服务模式（内置高保真 / 官方云端 / 本地 magic-pdf）、服务地址、API Token、Pipeline 模式（Pipeline / Hybrid / OCR）、公式提取开关、表格抽取开关、语言（Auto / en / zh）、测试连通。
   - **学术检索源**：arXiv 镜像源（官方 / 国内加速镜像）、Semantic Scholar API Key、CrossRef 邮箱标识、网络代理（Proxy URL）、自动拉取引用数开关。

4. **[4] 编译与沙箱 (LaTeX & Sandbox)**:
   - **LaTeX 编译**：编译器选择（WebAssembly 客户端 / Tectonic / pdfLaTeX / XeLaTeX）、保存时自动编译开关、防抖延迟（ms）、SyncTeX 反向跳转开关。
   - **代码沙箱**：执行引擎（本地 Pyodide / 远程 Docker）、沙箱端点、执行超时时间（秒）、默认绘图引擎（Matplotlib / Plotly）。

5. **[5] 智能体安全 (Agent & Guardrails)**:
   - 高危 Shell 命令拦截等级（严格拦截 / 需人工确认 / 放行）。
   - 破坏性文件写入保护（开启/关闭）。
   - 会话 Token 预算上限设置（例如 32k / 64k / 128k）。
   - 记忆沉淀机制（会话结束自动提炼开关、记忆范围: 全局 / 课题专属）。
   - MCP 协议权限与超时限制。

6. **[6] 偏好与备份 (General & Backup)**:
   - 界面外观主题（深色 / 浅色 / 跟随系统）。
   - 界面字号（紧凑 12px / 标准 14px / 宽松 16px）。
   - 代码与 LaTeX 编辑器字号（滑块 11px–18px）。
   - 任务完成自动切换画布开关。
   - 全局数据备份：导出 JSON 快照、从 JSON 导入恢复、清除缓存并重置。

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: 其余页面彻底移除内联设置，保持纯粹业务形态**
  - *Chosen Approach*:
    - 在 `RagStudioView` 中彻底移除 `isConfigOpen` 折叠表单及其内部的下拉框；顶部仅保留紧凑的当前生效参数摘要（如 `BGE-M3 · 256 Tokens · 阈值 ≥ 0.55`），附带小型设置图标按钮直接打开 `SettingsModal` 的 RAG 标签。
    - 在 `LiteratureHubView` 中移除 PDF 导入弹窗内的重复流水线模式选择，上传后直接使用全局配置的 MinerU 引擎参数执行解析。
  - *Why*: 严格落实用户指示“确保所有设置功能都在设置里修改，其余页面不再设置相关功能”，杜绝重复配置与认知混乱。
- **Decision 2: 界面纯度与紧凑性（Zero-Marketing, Pure Engineering Console）**
  - *Chosen Approach*: 彻底剔除大段文字说明、背景宣传语与彩色大横幅。所有配置项采用标准左侧标签或内嵌标签、等宽字体数字、标准单行高度（h-8）、单行紧凑开关。
  - *Why*: 符合科研与高阶开发者工作台的工具属性，最大化信息密度。
- **Decision 3: 全局响应式状态共享（Global State Synchronization）**
  - *Chosen Approach*: `settings` 状态统领在 `App.tsx`，通过 Props 传递给各业务组件；当在设置面板保存后，所有视图的渲染与后台引擎立刻读取最新参数。
  - *Why*: 无需页面刷新，修改立刻全局生效。
