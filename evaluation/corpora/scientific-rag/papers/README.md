# 原始论文

把获准使用的原始 PDF 放在本目录；manifest 固定相对路径、SHA-256、来源 URI、许可和一个主要类别。不要提交私有或无再分发许可的论文。目录中的本地 PDF 默认不进入 Git。

配额按唯一 PDF sourceHash 计数：双栏 10 篇；单栏、公式密集、表格密集、图像密集、扫描件、混合语言、长附录各 5 篇。精确类别键见 [scientificPaperQuotas](../../../lib/scientific-rag-corpus.mjs)。PDF 必须能实际打开且未加密；重复文件、换名或修改类别不能增加独立论文数量。真实性、来源许可和类别仍需人工核查，工具只校验记录和字节身份。
