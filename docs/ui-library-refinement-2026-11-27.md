# 2026-11-27 文献库界面验收

历史回归覆盖固定列表与 Inspector、自动导入、项目解除关联与撤销、永久删除和文献处理状态。正常及减少动态效果使用真实 Electron 窗口、隔离数据与受控服务。功能合同见[工作台文献库](research-workbench.md#文献库)和[文献入库](research-literature-acquisition.md)。

当时的 macOS 包使用带历史内容的独立 v76 夹具升级到 v77，核对备份、20 张业务表指纹、PDF、附件以及原生窗口中的项目、文献和文档读取。合成旧关系仍产生后台科学校验警告。

帧时间、严格帧预算缺口、测试命令及打包证据见[原始验收记录](https://github.com/ryzqi/Roc/blob/0ea0b6c730c0825ce1173325d946cd5457953131/docs/ui-library-refinement-2026-11-27.md)。物理触控板、系统输入法、VoiceOver、实际屏幕刷新率和外部服务仍需各自的环境证据。
