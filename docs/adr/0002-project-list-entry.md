# 项目列表作为入口，科研服务只在项目内

Roc 的默认入口是项目门户，不是某一个研究项目的工作台。打开应用永远先到门户；上次项目可以高亮或置顶，但不自动进入。没有项目 id 的刷新也落门户；带项目 id 的地址仍进入该项目。进入研究项目后才出现研究助手与项目文件；返回门户时卸掉当前项目，界面上不残留对话或代码。没有当前研究项目时，旧的 `page=chat` / `page=workspace` 地址回到门户，不打开对话或代码。带项目 id 的对话或文件地址进入该项目并打开对应科研服务。研究助手的历史会话属于当前研究项目，不存在全局历史侧栏。不属于任何研究项目的旧会话不在界面出现，也不自动挂到某个项目。

进入研究项目后，画布一次只显示一个面，研究助手在助手列（窄窗为抽屉），两者可同时打开。门户与工作台都是干活面，不放产品介绍横幅。

每个研究项目拥有自己的工作目录。创建时必须指定目录；一个目录同时只能属于一个研究项目。文件与代码打开的是该项目目录，不是全局计算目录。门户不提供工作区选择器；设置里也不再保留默认工作区。删除研究项目只删除 Roc 中的项目记录，不删除磁盘目录。这样对话/代码不会成为一级页面，也不会在未选项目时露出文件壳。

曾考虑启动恢复上次项目、项目内常驻项目侧栏、以及保留全局计算目录。前两者会让主页面重新变成工作台；后者会让未选项目时仍有文件上下文。
