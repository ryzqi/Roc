# 项目列表作为入口，科研服务只在项目内

## 决定

应用启动进入项目门户，不自动恢复上次项目。带项目 ID 的深链进入指定项目；没有项目时不显示助手、会话或文件工作区。进入项目后，助手与画布可以同时使用，会话始终属于当前项目。

创建项目必须指定工作目录，一个目录同时只属于一个项目。删除项目记录保留磁盘目录。门户和设置不提供脱离项目的全局工作目录。

路由归一、深链和项目切换行为由[工作台合同](../research-workbench.md#url-契约)维护。

## 理由与代价

项目是材料、对话和科研流程的共同边界。启动恢复上次项目、常驻项目侧栏或全局计算目录会使未选项目时仍有隐含工作上下文。门户增加一次项目选择，但明确了后续文件与工具操作的目标。
