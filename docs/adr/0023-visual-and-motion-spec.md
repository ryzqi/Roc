# 视觉与动效口径

视觉规格由 [`tokens.css`](../../src/renderer/styles/tokens.css) 定义，[`index.css`](../../src/renderer/styles/index.css) 映射为工具类；动效预设由 [`motion.ts`](../../src/renderer/shared/motion.ts) 定义。本 ADR 保留稳定决策与理由，不另存组件几何和时长表。

## 决定

- 只有一条 token 链：Tailwind `@theme` → CSS 变量 → 组件类名。颜色使用语义 token，系统字体与明暗主题共用角色体系，不引入第二套样式入口。
- 圆角固定为 6 / 8 / 12 / 16 四档，分别承载 chip、control、card、window；界面正文 13px、chrome 12px。按角色使用刻度，避免所有元素都呈现为卡片。
- 栏序固定为左栏 | 助手 | 画布，让助手紧邻资料、画布保留右侧工作空间。窄窗将前两栏转为抽屉；路由与状态合同见[工作台](../research-workbench.md)。
- chrome 选中态使用单色，accent 留给主操作和焦点；类别图标保留一致色相并通过 token 适配主题。状态同时提供文字或图标。
- 动效统一使用 `motion/react` 和共享预设，尊重 reduced motion；原生 `<details>` 保留键盘与读屏语义。动画用于说明状态变化，不添加装饰性等待。

## 取舍理由

| 做法 | 理由 |
| --- | --- |
| 使用系统窗口红绿灯 | `hiddenInset` 已提供真实窗口控件，自绘会重复 |
| 助手模型 pill 指向设置中心 | `settings.save` 保存整份文档；设置中心持有草稿，避免增加并行写入口 |
| 空会话直接进入输入框 | 减少欢迎横幅和演示提示词占用的工作空间 |
| 工具状态带文字标签 | 明暗主题与色觉差异下仍可区分 |
| 设置与管理保留桌面编辑宽度 | 多字段表单、编辑器和预览需要同时可读 |
| 文件面板持有预览 | `?file=` 统一选中状态，避免再建全屏模态 |
| 终端铺满画布，状态集中到底栏 | 保留可用终端行数 |

## 代价

栏序调整须同时核对布局、分隔条方向与键盘行为；较宽松的助手转录占用更多竖向空间。新增动效、Markdown 或编辑器依赖的实际体积由构建产物和 `pnpm check:renderer-chunks` 检查，预算不在文档重复维护。
