# 三栏工作台 IA

进入研究项目后，工作台固定为三栏：左栏（文件 / 文献 / 会话）、助手列、画布，加上抽屉与浮层。左栏的三个 tab 都是当前项目的从属视图，不是全局导航；门户态不显示左栏。

## 决定

- **左栏属于项目上下文。** 固定三个 tab：文件 / 文献 / 会话，只在项目路由出现。
- **助手列夹在左栏与画布之间**，画布占右边缘。列宽由分隔条调整，画布至少保留 360px。
- **`≤ 1099px` 时左栏与助手都改为抽屉**，盖在画布上；设置始终是浮层。
- **面表是唯一真理源。** 「有哪些面、每个落在哪」由 `src/shared/surfaces.ts` 声明：画布一级 tab、画布视图（`?view=`）、抽屉分区、浮层。
- **Token 链只有一条。** Tailwind 4 `@theme` → CSS 变量（`src/renderer/styles/tokens.css`）→ 组件类名。组件里禁止写死 hex，也不得并行引入第二套样式入口。
- **配置的唯一可写位置是设置中心。** 模型与密钥、嵌入与索引参数、文档解析开关、LaTeX 编译参数只在设置中心可写；业务面只读显示 + 跳转。

## 理由

进入项目后最高频的三件事是看文件、看文献、切会话；把它们放进左栏，比藏进抽屉与浮层每次少一次开关。三个 tab 都是当前项目的从属视图，不引入全局一级导航，所以仍然满足「不做 SaaS 仪表盘」的约束。

## 代价

- 三栏在窄窗互相挤压，所以 `≤ 1099px` 需要整体退化为抽屉。
- 顶栏要为系统红绿灯留出左侧空间，门户页的按钮数量需要克制。
