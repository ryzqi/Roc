# Review Response Matrix

审稿矩阵属于当前项目的论文工件。原始审稿意见、人工回复与处理状态按完整矩阵追加版本；保存不会修改正文、证据、科学支持审核或人工闸门。

## 合同

`research.responseMatrix.save` 需要主进程根据实际 IPC sender 绑定的人工身份。renderer、模型和请求参数不能自授身份。输入必须给出项目、论文工件、幂等 requestId、当前工件快照版本、精确上一版 ID/hash、修订理由和完整意见集合。

每项包含稳定 commentId、审稿人和原始意见。既有意见不能被删除或改写；新的处理结果保留原意见并追加版本。状态由人工明确选择：

| 状态 | 要求 |
| --- | --- |
| `open` | 保持未处理；可保存调查中的回复、位置和证据 |
| `addressed` | 非空回复，至少一个修改稿中的精确位置 |
| `declined` | 非空回复，记录人工未采纳理由 |

位置绑定当前保存的主张 ID/hash、UTF-16 字符范围和完整原文；小节、主张版本、修改稿 LaTeX/contentHash/claimsHash 与所选项目 Evidence 一起冻结。位置只能来自该修改稿。所选 Evidence 必须处于 `recorded` 状态；关联本身不构成语义支持确认。文字或结构修改可以只绑定修改稿位置，科学证据需要人工明确选择。

模型审稿意见可显式绑定 `finding` 的工件 ID、reportHash 和 findingId，审稿角色及原意见必须与保存报告完全一致；修订稿沿实际输入链继承旧 findings。此类意见标为 `addressed` 时必须绑定当前修改稿的 Verifier 报告，且报告覆盖全部修改位置的主张。报告仍是需人工审核的模型建议，不能代替科学支持确认。接受论文前要求所有关联 Reviewer findings 已有非 `open` 的人工处置；普通外部意见的状态不自动决定接受或拒绝。

同一请求和 sender 的精确重试返回原回执且零写入。请求内容、sender、parent 或工件版本冲突明确拒绝。归档项目不能追加新版本。通常只有当前阶段的有效草稿可编辑；例外是项目处于 `review`、该阶段为 `waiting_approval`，且工件为当前审稿记录绑定的已批准输入稿，此时允许人工追加回复矩阵。该例外不修改已批准正文，也不接受论文或推进阶段；其他已批准或非当前阶段工件仍只读。

## 当前核验与历史

`research.responseMatrix.inspect` 读取当前保存修改稿和最新矩阵，返回报告 hash、当前工件版本、原人工处理状态及 `reviewCurrent`。修改稿或所选 Evidence 的内容变化使原绑定失效；原状态保留供重新核对，不能被当成新修改稿已经处理完毕。过期正文必须先重新保存，不读取成功式缓存回退。

`research.responseMatrix.history` 按 limit/offset 读取最多 100 条，标记 `stored_receipt`。它验证保存字节、索引、父版本和内在位置/稿件/hash 合同，不要求恢复当前来源。历史不能证明当前来源或意见已经重新核查。没有审核时当前 review 为 null、各状态 ID 集合为空，不能推断没有外部审稿意见。

`research_response_matrices` 保存人工回复，不创建或推断审稿意见。没有旧 API、旧 schema 或默认字段兼容层。

## 实施边界

现有论文工件抽屉提供“检查审稿回复”惰性入口。打开前零矩阵请求；人工编辑完整矩阵，单条意见表单保留桌面信息密度。已保存原始意见/审稿人只读，处理状态、回复、精确修改位置和证据显式编辑。可选择完整段落或 UTF-16 字符范围，保留选区空白。待关联位置不能被整份保存静默丢弃。新意见只有保存前可移除，旧意见需要保留并记录处理结果。

未保存锁定、迟到响应隔离和精确重试遵循[工件检查器](research-artifact-inspector.md)。修改稿变化后的旧“已处理”标为历史判断；当前核验失败隐藏旧成功数据，独立分页历史仍可读。只读、归档或不满足编辑条件时不发保存请求。

工件快照提供可空的 `responseMatrix` head，独立所选 Evidence 也进入来源闭包；追加回复、稿件或来源变化会撤销旧审批版本与导出 seal。阶段完成、人工审批、任务验收和导出复用真实来源核验，异步读取结束后再次同步检查整个工件集合。

最新矩阵及全部历史进入[导出科研审核快照](research-exports.md#科研审核快照)。当前 `open` 状态如实保留；历史可读不表示过期稿件或来源能通过当前审批。
