# 外部反馈与实验回流

正文工件检查器可从项目内导入 Word 或 PDF 反馈。Word 保留原批注、插入和删除建议及其来源范围；PDF 保留注释页码、矩形和可用坐标。只有唯一的准确原句才能定位到当前主张，多义或未匹配意见会明确显示。

用户选择并合并意见后，原始意见进入现有回复矩阵，正文不被自动修改。原评论、作者、文件哈希和条目身份保留。修改稿件或来源后需重新核对；有记录的稿件分支可继续处理原意见。插入、删除建议仍是外部建议，不能替代人工科学判断。

外部实验使用人工确认的约定，记录指标定义、预期文件和回传格式。绑定外部机构与唯一任务编号后，可以退出并在重启后继续等待。Roc 不代为提交远端任务；读取等待记录不会重复发送作业。

回传 JSON 必须匹配约定哈希和外部编号，指标使用约定单位，声明文件逐一核对真实字节。导入时冻结原始 JSON 与声明文件。回执和由它派生的方法、图源、证据始终标注“外部报告、未经独立核验”。结果可捕获为原始文件证据并进入正文和回复，图源沿现有图稿服务渲染。

助手使用 `research_collaboration_read` 读取原意见和外部回执，通过原提案与人工审核继续任务。外部文本、作者名、报告方法和环境陈述都是输入材料，不能扩大工具权限，也不证明已独立复现。
