# 变更影响与定向修复

工件检查器中的影响报告按准确的工件版本读取记录关系。助手也可通过 `research_inspect_impact` 查询工件、证据或结果回执的影响。

报告分别列出主张证据、数值映射、图稿材料、回复、期刊审核、导出和阶段上下文。阶段上下文可能包含很多当时已批准的工件；它表示运行读取范围。影响报告覆盖已记录关系，来源变化后需要重新读取。

定向修复要求人工核对影响报告、目标产物、各阶段输入和修复理由。直接材料依赖的下游产物需要一起处理；只有运行上下文关联的产物可由用户明确选择。旧工件与回执留在历史，新任务沿用现有执行图，创建新运行并重新审核。

修复只将所选产物从活跃流程中移出。其他已批准产物保留在项目中。修复阶段的闸门核对本次新草稿，审稿和修订继续使用既有周期。稿件证据失效时需要新的写作和审稿，不能复用旧稿批准。
