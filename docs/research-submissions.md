# 投稿配置与投稿包

期刊检查区可以将已核对的期刊规则保存为复用配置，并设置 PDF 页数、声明文字、匿名核对、原生 Word 表格数量及补充文件要求。配置版本固定来源链接、摘录和日期；切换配置可以比较增删和变更的规则。

在已批准导出中选择配置，生成署名或匿名投稿包。Roc 从同一冻结来源重新编译，复制明确选择的图稿和补充文件，保留父导出的身份。匿名包使用用户指定的替换项，原稿保持不变；替换项和恢复关系只存于私有数据库。投稿包包含重新生成的正文源、PDF、书目、所选文件和精简清单。

预检读取实际编译 PDF 和所选文件：检查页数、声明、metadata 与所给身份词，并识别 DOCX 原生表格。结果区分通过、失败和人工核对。正文、引用和图稿继续按所选期刊规则检查。图像内容、未声明身份线索等不能自动排除，需要人工核对。

失败项会阻止本地交付；人工项要求填写核对说明。保存通过原生文件对话框选择位置，并在写入前核验包内文件及 ZIP。父导出和历史投稿包保留，准备和本地交付都不向期刊发送文件。
