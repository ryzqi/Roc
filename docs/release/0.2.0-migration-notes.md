# 0.2.0 迁移发布说明（草稿）

本次发布把 Roc 的渲染层整体换成新前端（原 `research-studio/` 的设计与 IA），**不向后兼容**：
旧壳与 `research-studio/` 目录都已删除（ADR 0022），后端 DeepAgent / Kernel / 插件 / SQLite 契约零改动
（`pnpm check:ipc` 为证）。

## 用户可感知的变化

| 变化 | 之前 | 现在 |
| --- | --- | --- |
| 默认入口 | 科研工作台（顶栏 + 画布，无全局左栏） | **项目门户**（卡片网格）；进入项目后才是三栏工作台 |
| 项目内布局 | 顶栏 + 画布；助手是叠层 | **左栏（文件 / 文献 / 会话）+ 画布 + 助手列**；≤1099px 左栏与助手变抽屉 |
| 导航 | 阶段条是项目内主导航 | 阶段条只在总览与阶段工作区出现；项目内视图走 `?view=`（14 个视图） |
| 科研服务 | 独立导轨/壳层（活动、文件、连接器、技能、记忆、诊断） | 落成画布视图（`view=activity/tasks/files/changes/terminal/mcp/skills/memory/diagnostics`）与 Git / 管理抽屉 |
| 设置 | 设置页（独立视图） | **设置浮层**（⌘,），12 个分区，脏状态条 + 关闭确认 |
| 主题 | 深色 | 深色 / 浅色 / 跟随系统（「应用基础」分区里的外观源） |
| 视图 id | `page=chat` / `page=workspace` / `page=git` 等独立页 | 规范化到 `page=research&view=...&assistant=1`；**旧参数不保留别名** |
| 测试 id | `research-*` / `chat-*` / `workbench-*` / `settings-view` | 新壳前缀族（`design-system/MASTER.md` §12）；**不做事后别名映射** |
| 工作目录绑定 | 设置里的默认工作区 + 项目表单 | 项目表单必选；进入项目后可在左栏重新绑定（`sidebar-files-binding`）；设置里不再有默认工作区 |

## 数据与兼容性

- **项目、会话、文献、实验、图稿、导出数据不迁移、不转换**：它们都在 SQLite / 工作目录里，schema 未变。
- `localStorage` 只保留 `roc.ui.*`（界面偏好）；迁移前旧壳写的键在首次启动时被忽略（不读取、不删除）。
- 文件写入账本 `source` 前缀由 `renderer-next:*` 改为 `renderer:*`（只影响账本里的来源字符串）。
- 密钥仍在 Electron `safeStorage`；本轮把「密钥尾号掩码」登记为后端缺口（后端只回 `stored: boolean`）。

## 后端缺口（登记为任务单，不用假数据替代）

| 编号 | 缺口 | 界面现状 |
| --- | --- | --- |
| B24 | 没有「只选目录、不绑定工作目录」的对话框 | 技能导入手填绝对路径，并写明原因 |
| B25 | `memory.entries.search` / `memory.entry.remember` / `mcp.tools.get` 实现了但没注册进 IPC | 会话检索走 `agent.sessions.search`；工具名走装配预览 |
| B23 | `research.embedding.save` 每次都要明文 `apiKey` | 嵌入编辑区每次提交都要求重新输入 |

**B26 已修复**：主进程现在把工作插件持有的同一个 `WorkspaceService` 交给记忆插件
（`main-kernel-bootstrap.ts`），`workspace.select` 绑定目录后 `memory.status.workspaceHash` 不再为 null，
`/memory/workspaces/current/{AGENTS,MEMORY}.md` 两个项目槽位可读可写。此前它们如实标为不可用、
禁用保存；现在只有在**没有绑定工作目录**时才这样显示，并提示去左栏绑定。
