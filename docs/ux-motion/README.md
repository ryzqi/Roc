## 验收边界

自动化使用隔离资料根和受控服务，不读取或修改真实研究资料。生产构建 RAF、输入响应代理、Chrome 主线程 trace、Electron 资源采样分别报告，不能合称屏显 FPS。120Hz、低功耗、第二台 Mac、VoiceOver、物理触控板、中文 IME 和真实外部服务必须有各自的实机证据。未取得证据时，标记待验证。

每阶段只运行证明该变化所需的检查；共享组件和壳体的影响在 P6 汇总回归。每阶段提交前核对差异和 `git diff --check`，不为静态文案或可逆样式改动添加同构测试。
