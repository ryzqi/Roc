# 证据矩阵与论证大纲

阅读笔记和正文工件的“论证大纲”按需读取当前项目主张、原始证据及支持、反证、限定关系。矩阵保留关系的审核状态、条件和版本变化，缺少证据或人工确认时明确提示。

每节大纲记录标题、要回答的问题、准确主张、适用条件和缺口。助手可生成大纲提案，用户核对矩阵后保存不可改写的版本。生成正文时重新核对所选主张和来源，再将这些段落按大纲顺序写入草稿。复制其他工件的主张会产生新的主张身份，支持关系需重新审核。

工作稿已绑定的正文使用稿件同步修订，或由大纲创建新草稿。问题、适用条件和缺口保留在大纲中供写作和审稿使用。

系统综述的提取区可以选择一至五篇已纳入全文，按冻结协议试查提取列。报告分别显示已记录、未提取、缺失、无法判断和来源变化，并核对绑定文件与已有提取证据。试查只覆盖所选样本，逐篇审核继续使用原有入口。
