# 工作稿同步

在写作画布打开“稿件同步”，选择已保存的正文工件。可以将受控正文生成到一对新的 `.tex` 与 `.bib` 文件，也可以关联项目里已有的文件。生成操作只创建新文件。文本编辑器保留现有草稿，差异以已保存的文件为准。

Roc 生成的工作稿用注释锚点标记每个段落。已有工作稿支持单文件的普通 `\section`、纯文本段落和 `\cite`，首次关联需要小节标题和段落数量与底稿对应。同步页显示现有结构中的逐段文字、引文和标题修改。复杂宏、段落或小节结构改动、书目内容与资料库不符都需要在采纳前处理。

勾选修改并为变动的段落选择实际证据。采纳会重新读取文件并核对预览版本，再更新受控正文和主张版本。其余修改保留在工作稿中。已批准稿件的修订使用当前修订阶段的新工件，重新核对证据与人工审核。

阶段提交和导出读取关联工作稿。未采纳差异、无法读取的文件或书目冲突会阻止继续。既有交付历史可在原工件中核查。助手可通过 `research_inspect_workflow` 的 `manuscript_sync` 查看已保存文件的差异。
