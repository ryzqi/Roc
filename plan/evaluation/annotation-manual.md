# 独立样本与盲审标注手册

状态：Draft；适用于 [S01 协议](../evaluation-protocol.md) 的新 corpus。
此手册没有已经完成的人类标注，不为原 16 项补造审核身份。

## 来源与分配

来源登记保留真实标题、归属、许可原文/记录、版本、原文 locator 和内容 SHA-256。
未经许可的材料不进入冻结包。摘录需足以保留条件、样本、比较对象和限定词。
同论文、共享数据、同模板或依赖的故障变体归为一个 connected cluster；
两论文任务把关联来源合并成同簇，再划 split，不能用题目改写制造独立性。
不同来源有真实依赖时，人工合并簇；hash 检查只发现确定性重标，不能识别语义重复。

具体来源簇 ID、train/dev/holdout 及八族配额先注册并留时间/hash，
随后才向审核者发包。holdout 不给开发者、writer 或调参流程读取；
dev 用于 pilot，train 用于设计。发现泄漏时废弃该协议，重新收集/冻结，保留旧审计。
holdout 目标 200 项，每族至少五簇；难度由前置步骤、证据数量和恢复复杂度判定，
不能按候选模型表现回填 easy/moderate/hard。

## 科学主张的两次独立审核

两位审核者分别获得匿名任务、claim、来源版本和 locator；
看不到 writer 身份、A/B arm、另一位标签或模型评分。实施者的模型不是 gold reviewer。
每条 claim 按以下标签记录理由和原文证据：

| 标签 | 判据 |
| --- | --- |
| supports | 原文直接支持同一对象、数值/方向及适用条件 |
| conditional | 仅在明确条件、亚组、方法或时间窗下支持，必须写出条件 |
| contradicts | 同对象与条件下证据否定该主张，保留反证及比较方向 |
| irrelevant | 材料不涉及该对象/关系，不能用关键词相似度判支持 |
| unverifiable | 原文缺失、locator 无法定位或数据不足，保留缺失原因 |

记录 claimId、来源 ID/版本、页/段/表格单元、原文引用、单位、样本量、数值映射、
不确定性、标签、条件、理由和审核时间。数值/单位/引用键先做确定性检查，
“科学支持”由人工独立审核；同一 writer 模型的自评不能升级为人工认可。
审核者声明自己未参与该答案生成，匿名稳定 reviewer ID 仅用于去重。

双审包合并时保留两份原始决定。任何标签、条件或数值分歧都标 disagreement；
第三位仲裁者查看分歧和证据后填写 arbitration，不能覆盖或删除原审。
形成 gold 后记录 reviewedAt、annotationRef/hash；有分歧还记录 arbitrationRef/hash。
hash 锁的是 JSON 记录，reviewer 独立性和许可仍需负责人的人工核实。

## 操作家族的 gold 与真实证据

文件/脚本 gold 检查文件名、内容/hash、约束和方法；AST 验证只做解析，不执行任意提交代码。
MCP、权限、取消、DAG 必须使用受控测试服务、真实请求/receipt、
文件/进程/网络 sentinel 与状态账本观察，不能只接受 agent 声称“已阻止/已恢复”的 JSON。
初态、可见资源、时钟、权限、故障注入、重置及清理记录单独保存。
故障场景标 synthetic，不当作科学蕴含证据。
当前 fixture validators 仅测这些结构化合同；真实专项环境还未建立。

## A/B 人类盲审

独立协调人以 seed 固定匿名 run ID 和展示顺序，封存 arm 映射。
审核者看相同任务和原文证据，按准确性、条件保留、引用可复查性、完整性、写作可用性逐项评分。
评分表不包含运行价格、速度或开发者身份；保留两人评分、理由和仲裁。
失败、空输出和无法核验不得从样本表删除；标明原因并保留分母。
最后由协调人合并客观 runner 报告和人工报告，解盲时间及映射 hash 写入记录。
样本或审核不足时报告 insufficient；不以“全部 fixture 通过”补齐科研结论。
